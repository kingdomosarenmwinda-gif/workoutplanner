# Gym Platform Frontend

A React + Vite + Tailwind CSS frontend for the Gym Platform.

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS 3
- Axios

## Getting Started

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## Deployment

### Render

Deploy as a static site using `render.yaml`:

1. Connect your repository to Render
2. Select the `gym-platform-frontend` service
3. Render runs `npm install && npm run build` and publishes the `dist` directory

### Other platforms

Build the project and deploy the `dist` folder to any static host (Netlify, Vercel, GitHub Pages, etc.).
